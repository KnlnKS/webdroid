# Wasm backend research

Research only: micro-benchmarks, probes, corpus statistics and the platform survey; nothing in `src/` or the tests imports it. The plan is `docs/wasm-backend-plan.md`.

Setup: `cd research/wasm && bun install` (binaryen, wabt, playwright from the repo root). Timing scripts
(`micro/*.mjs`) need Chrome and report indicative single runs.

- `probe.mjs <chrome|chromium|webkit> [--flags=a,b] [--nolimits]` feature and limit matrix (see `platform-status.md`)
- `probe-tiering.mjs hints|cache [chrome|chromium|node]` compilation-hint and code-cache checks; the instrumentation is V8's trace output read with `DEBUG=pw:browser`

- `micro/` microbenchmarks; `gc/` Zig mark-sweep (`zig build-exe gc.zig -target wasm32-freestanding -O ReleaseFast -fno-entry -rdynamic --import-memory -femit-bin=gc.wasm`)
- `dexstats/`, `survey/` static analyses (run from their directory, `dexstats` over the compiler in `src/wasm/compiler`; `survey/out` is regenerated by `ast-survey.ts`)
- the compiler, linker and host of the Wasm backend are `src/wasm/{compiler,link,host}`; their suites are `scripts/wasm/` (`bun run wasm <suite>`, see the header of `scripts/wasm/run.ts`; `watdump` prints the code generated for a method, `g1` times the jbench workloads in node and headless Chrome, plan 4.7), the Java fixtures `tests/fixtures/wasm/java/`
- `*.md` reports from the analyses
