## Verification and evidence limits

- The original-20 boot sweeps rendered 20/20 and collected per-process diagnostics. The last reported sweep had zero called native requirements and 29 distinct boot-path missing entries, mostly optional probes or private services. That count does not describe untouched features.
- Fast-flow matrices reached 10/13 and 9/13 in earlier serialized runs. A later serialized replay reached 12/13 checkpoints in 245.3 seconds; only Doodle Jump missed its retained title frame-rate gate on SwiftShader. The observed genuine platform gap was ChatGPT's `media_projection` service; TikTok still needs guest child-process semantics for `clone` syscall 220. Optional vendor/AndroidX probes and app logcat messages account for many of the 330 reported gaps. This is observed-path coverage, not feature completeness.
- An earlier WebView change routes form POSTs through the proxy. Amazon's product Add to cart sent its body and Android user agent, got HTTP 200, redirected to the cart, and displayed “Added to cart.” A separate simple WebView form POST echoed both fields through the same proxy. Typecheck, all 1,377 tests, and Amazon XAPK smoke compilation passed with zero method failures **before the merge**.
- A later in-memory Maps GL trace counted about 100 sprite calls and 17 label calls with linked shaders and bound textures. It saw no map-geometry program. `URLConnection.getInputStream()` returned an open stream for two HTTP 200 map-style responses, followed by `disconnect()` and close with zero bytes read. This narrows the symptom but does not establish why the app discards them. No probe code was committed.
- Initial launch and feature telemetry cover observed paths only. Inspect each step's `run.json` for `newMissing`, `newErrors`, `nativeRequired`, layout/draw errors, completed rendering, and advancing `wd.ticks`; confirm diagnostics reached relevant child processes. Do not count logcat `E/` lines as missing APIs without evidence.

## Next investigation order

1. Trace why Google Maps' bundled client closes map-style streams unread and does not issue map-geometry draws. The GL surface, sprites, labels and tile-response byte transport work on the observed path. Avoid changing GL or transport without a causal finding.
2. Trace whether YouTube's page near `0x10004d20` was ever mapped, then its branch target calculation. Compare `?jit=0` and narrowed JIT ranges under matching inputs. The page is free after a faulting replay, but this alone does not identify where the invalid pointer came from.
3. Address TikTok's `clone` only with correct guest child-process semantics; do not fabricate success. Investigate the Cut the Rope intro's codec-to-Unity handoff and Doodle Jump performance with working rendering and serialized measurements.
4. Expand each app's shallow path to real feature completion and persistence. Check Resy's live timeouts, Among Us full matches, authenticated paths where credentials are available, and Maps/Mihon backup with populated data. Hosted UDP is a deployment capability gap for the Bun-only online paths.

Run the Bun server on an unused port, then use `bun run corpus` for startup coverage and `bun run e2e --full --jobs 1` or targeted flows for interactions.
