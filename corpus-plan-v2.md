# Compatibility corpus handoff

Status: 2026-09-24. This is the working plan for the 15 open-source APKs in [docs/compatibility-corpus.md](docs/compatibility-corpus.md), which records their source links, exact filenames, SHA-256 hashes, initial missing calls and longer investigation notes. The APKs are ignored by Git and live in the main checkout's `apks/` directory. All 15 have drawn an initial frame in the repeat launch scan, but **none has been established as fully usable**. Missing-call telemetry covers only executed paths, and the initial launch results in that document are historical, not the current failure list.

## Findings that matter for the next pass

- The corpus has already exposed shared correctness bugs, not just absent methods: stale `RandomAccessFile` snapshots across parallel writes; a native file handle with a shorter view than the VFS's logical length; a freed joinable pthread handle reused before `pthread_join`; source annotation arrays without Java array types; and external-storage files not restored before app startup. Their mechanisms and evidence are in [docs/implementation-history.md](docs/implementation-history.md).
- Organic Maps' second file bug made a byte-perfect Monaco download fail the app's BLAKE3 check. The latest fix always updates an open VFS file's data view when `vfs.write` publishes bytes. A focused test covers a longer view of the same backing buffer. `Collections.rotate(List, int)` now writes through the list iterator, including live sublists. Opening a place found that missing call.
- Starting Organic Maps navigation found `Context.createAttributionContext` and `MediaPlayer.setAudioAttributes`. Attribution contexts retain the base context and expose the requested tag/source. MediaPlayer now reads file-descriptor byte ranges, releases blob URLs, and calls its prepared listener on preparation rather than listener registration. Android's [Context](https://developer.android.com/reference/android/content/Context) and [MediaPlayer](https://developer.android.com/reference/android/media/MediaPlayer) contracts guided these changes. The final route snapshot had no missing call, but voice playback requires a separate real-app check.
- NewPipe's generated DASH document needed standard DOM construction and JAXP transformation. Its visible player is a `SurfaceView` subclass that skips `super.onLayout`; surface creation must follow frame changes independently of that override. The same surface fix enabled Gallery's short video fixture. Neither run establishes audio or broad codec/container support.
- `androidx.window` sidecar and extension provider classes are optional OEM probes. Do not fabricate them just to clear telemetry. Treat other empty missing lists as observed-path evidence only; check child processes, `run.json`, frames, interaction and persisted state.
- Do not implement ad or ad SDK APIs as part of this corpus. Use framework, DEX and native evidence for general behavior; avoid app-specific substitutes.
