# Compatibility corpus handoff

Status: 2026-09-25. This is the working plan for the 15 open-source APKs in [docs/compatibility-corpus.md](docs/compatibility-corpus.md), which records their source links, exact filenames, SHA-256 hashes, initial missing calls and longer investigation notes. The APKs are ignored by Git and live in the main checkout's `apks/` directory. All 15 have drawn an initial frame in the repeat launch scan, but **none has been established as fully usable**. Missing-call telemetry covers only executed paths, and the initial launch results in that document are historical, not the current failure list.

## Findings that matter for the next pass

- The corpus has already exposed shared correctness bugs, not just absent methods: stale `RandomAccessFile` snapshots across parallel writes; a native file handle with a shorter view than the VFS's logical length; a freed joinable pthread handle reused before `pthread_join`; source annotation arrays without Java array types; and external-storage files not restored before app startup. Their mechanisms and evidence are in [docs/implementation-history.md](docs/implementation-history.md).
- Organic Maps' second file bug made a byte-perfect Monaco download fail the app's BLAKE3 check. The latest fix always updates an open VFS file's data view when `vfs.write` publishes bytes. A focused test covers a longer view of the same backing buffer. `Collections.rotate(List, int)` now writes through the list iterator, including live sublists. Opening a place found that missing call.
- Starting Organic Maps navigation found `Context.createAttributionContext` and `MediaPlayer.setAudioAttributes`. Attribution contexts retain the base context and expose the requested tag/source. MediaPlayer now reads file-descriptor byte ranges, releases blob URLs, and calls its prepared listener on preparation rather than listener registration. Android's [Context](https://developer.android.com/reference/android/content/Context) and [MediaPlayer](https://developer.android.com/reference/android/media/MediaPlayer) contracts guided these changes. The final route snapshot had no missing call, but voice playback requires a separate real-app check.
- NewPipe's generated DASH document needed standard DOM construction and JAXP transformation. Its visible player is a `SurfaceView` subclass that skips `super.onLayout`; surface creation must follow frame changes independently of that override. The same surface fix enabled Gallery's short video fixture. Later PCM diagnostics established a running audio output path in NewPipe; audible listening and broad codec/container support remain open.
- KeePassDX's vault flow now uses general JCA stream wrappers, XmlPull serialization, ViewGroup default layout params and `InsetDrawable` constant state. Separate `SQLiteOpenHelper` instances now retain separate connection-local TEMP schemas. Picked single-file document handles persist with their URIs in IndexedDB, and the saved vault reopened after reload. The browser diagnostic supplied a real OPFS file handle in place of a picker so synthetic taps did not lose browser user activation; test a physical picker gesture separately.
- AntennaPod's direct RSS path needed wrapped TLS sockets to stay logically connected, virtual Reader dispatch, `StringReader` marks, CharBuffer array backing, SAX parsing and token-specific Handler cancellation. `java.vm.name` now reports Android's `Dalvik`, so OkHttp selects its Android platform path and artwork loads. A match-parent child positioned beside an anchor now measures only the remaining RelativeLayout span. MP3 decoder exposure and `SharedMemory` enabled Media3 output. Bun strips `Content-Length` from a streamed proxy response, so the proxy carries the verified upstream length separately for Java URLConnection; Media3 then reports a finite duration and the app updates its clock.
- AntennaPod's download path called `PendingIntent.getForegroundService`, which now retains a distinct operation kind and starts the service in foreground mode. The media retriever previously fed MP3 bytes to its MP4 parser. It now recognizes MPEG Layer III frames, reads ID3 embedded artwork and returns duration/bitrate metadata. The completed download no longer logs the former invalid-media exception.
- OpenTracks needed pending `bindService` connections to receive callbacks when a service starts later without `BIND_AUTO_CREATE`. Its track provider exercised `SQLiteQueryBuilder`, `ContentValues.putAll`, and content observer notifications. Recording and drawing exercised java.time and Stream operations, ViewGroup layout mode and LogPrinter. A recording notification used `PendingIntent.getActivities`, whose stored stack now launches in order when sent. A tap on the recording screen's Stop control only displays the app's “hold to stop” hint; a long press opens its finish screen.
- `androidx.window` sidecar and extension provider classes are optional OEM probes. Do not fabricate them just to clear telemetry. Treat other empty missing lists as observed-path evidence only; check child processes, `run.json`, frames, interaction and persisted state.
- Do not implement ad or ad SDK APIs as part of this corpus. Use framework, DEX and native evidence for general behavior; avoid app-specific substitutes.
